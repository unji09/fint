# 설계 문서 인덱스

> 이 디렉토리는 프로젝트별 아키텍처/설계 문서를 보관합니다.
> Claude는 필요 시 이 문서들을 참조합니다.

## 읽는 순서

1. 이 README로 전체 구조 파악
2. 필요한 도메인의 문서만 선택적으로 참조

## 디렉토리 구조

docs/
├── README.md              ← (이 파일) 문서 인덱스
├── backend/               ← 백엔드 설계 문서
│   └── (프로젝트별 추가)
├── frontend/              ← 프론트엔드 설계 문서
│   └── (프로젝트별 추가)
└── (필요한 도메인별 디렉토리 추가)

## 문서 작성 가이드

- 파일명에 번호 접두사로 읽기 순서 표시 (00-overview.md, 01-entities.md ...)
- 한 문서에 한 주제만
- Claude가 context에 올리기 좋게 문서당 적정 길이 유지 (200줄 이내 권장)
