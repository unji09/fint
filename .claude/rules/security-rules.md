# 보안 컨벤션 (OWASP Top 10 기준)

- SQL Injection 방지: 네이티브 쿼리 사용 시 파라미터 바인딩 필수. 문자열 연결로 쿼리 작성 금지
- XSS 방지: 사용자 입력을 응답에 포함할 때 이스케이프 처리
- 인증/인가: 엔드포인트별 접근 제어 확인. 인가 없는 API 노출 금지
- CSRF: 상태 변경 요청(POST/PUT/DELETE)에 대한 CSRF 보호 확인
- 민감 데이터 노출 금지: 비밀번호, 토큰, 개인정보를 응답/로그에 포함하지 않음
- 보안 헤더: Content-Type, X-Content-Type-Options, X-Frame-Options 등 적절히 설정
- 의존성 보안: 알려진 취약점이 있는 라이브러리 사용 금지
- 입력 검증: 모든 외부 입력(요청 파라미터, 헤더, 바디)에 대해 타입/길이/범위 검증
